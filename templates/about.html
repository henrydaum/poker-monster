About Poker Monster

Poker Monster is a fun and profoundly simple turn-based strategy card game, with a theme of good versus evil.

It took a year to develop the rules of the game. Originally, this was a physical card game with actual cards, but it has since been computerized and hosted on this website. The credit for the name of the game goes to my father and the art was created by my sister. Her website is charlottedaum.com

About the AI

There is an AI that has been developed for users to play against on this website. It is a deep artificial recurrent neural network with almost a million parameters that has been trained on a GPU for tens of thousands of games. It learned everything it knows through self-play reinforcement learning. The code itself was written in Python using the PyTorch library.

The full open-source code is available on GitHub.

How to Play Poker Monster

Please visit this website to learn the basics of the game and the theory behind Poker Monster. Full disclosure: this is the best way to learn the basics.

Playing on this website is very easy. All you have to do is click the blue buttons on the left side of the screen. The game board on the right side of the screen contains almost all relevant information needed to make an action. The visual format mimics the physical game.
